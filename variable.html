Variable Interpreter

Format: [Value/Cmd][Row][Col][Layer]
• Rows/Cols/Layers: 1 to 9 (Bottom: 1, Top: 9)
• 1-9NNN: Add digit to cell
• SNNN: Subtract value | CNNN: Clear cell
• DNNN: Decrement cell by 1
• JNNN / KNNN: Jump loop if non-zero
• MNNN / PNNN: Mark source / Paste cell value
• ONNN: Output Char | UNNN: Output Num
• RNNN: Read user input into cell
• 0000: Full ASCII output sweep (L9 → L1)
