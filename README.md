Variable

An esoteric programming language

3D grid esolang with 729 memory cells and extended commands

NNNN (Set cell value)

SNNN / CNNN / DNNN (Subtract value / Clear cell / Decrement cell by 1)

JNNN / KNNN (Jump loop if non-zero)

MNNN / PNNN (Mark source / Paste cell value)

ONNN / UNNN (Output Char / Output Num)

RNNN (Read user input into cell)

0000 (prints the ascii value of each position in reading order)

Note: features jump loops across a bounded 729-cell grid

Computational class: finite state machine

This includes: variable.html which is an interpreter
